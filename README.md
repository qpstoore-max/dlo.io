# مراعي تيماء

متجر إلكتروني عربي (RTL) لبيع الذبائح واللحوم الطازجة. صفحة واحدة بلا أي أدوات بناء: كل التنسيق والجافاسكربت داخل `index.html`.

## المحتويات

```
index.html    الموقع كاملًا (التنسيق + السلة + المنتجات)
.nojekyll     يمنع GitHub Pages من معالجة الملفات
README.md     هذا الملف
```

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا (Public).
2. اضغط **Add file ← Upload files** وارفع `index.html` و`.nojekyll` و`README.md` مباشرة في جذر المستودع، بدون مجلدات.
3. اضغط **Commit changes**.
4. من **Settings ← Pages** اختر **Branch: main** و**Folder: / (root)** ثم **Save**.
5. بعد دقيقة أو اثنتين يعمل الموقع على `https://USERNAME.github.io/REPO/`.

للتأكد أن النسخة الأخيرة منشورة، انظر إلى أسفل الصفحة: يجب أن تظهر عبارة «إصدار 3.3».

## التعديل

افتح `index.html` بأي محرر نصوص:

| المطلوب | الموضع |
|---|---|
| رقم الواتساب | ابحث عن `966550368909` |
| المنتجات والأسعار | المصفوفة `PRODUCTS` داخل وسم `<script>` |
| الألوان | المتغيرات أعلى `<style>` داخل `:root` |
| أوقات العمل والتواصل | قسم `<footer>` |
| آراء العملاء | قالب معلّق في الملف باسم «آراء العملاء»، أضف فيه تقييمات حقيقية فقط |
